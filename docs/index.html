App flow

Green is done. Amber is in progress. Grey is not started. Yellow diamonds are decisions, not screens. After a valid OTP the app checks whether the mobile is already registered. Existing user: the app checks for an active rental or material booking (any assigned machine / material order). If yes, Quick Booking opens first; Close/Back goes to Home. If none, go to Home. New user: Sign Up Completed popup — Contact us to Register opens Help & Support, or Register Yourself continues registration and then Home. Invalid OTP stays on the OTP screen. Rental-owner Quick Booking (9000000001) is done — 40 isolated cases. Material Vendor Quick Booking (9000000017) is done — Landing 6, Accept 1 (one-step, no Assign machine), Decline 1 (reason sheet + Confirm Decline + Request Declined), Edge 6 (Close/Back skipped after empty queue). Dev blocker #16: rental Assign machine Confirm stays disabled when operators are busy. Operator Quick Booking is not started. Operator-specific existing-user landing after OTP is not on this chart yet.
