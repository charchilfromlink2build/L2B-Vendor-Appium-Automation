L2B Vendor — Appium Automation

Black-box UI suite for the Vendor QA APK (com.l2b.app.qa). Tests run top to bottom in this order. Green boxes are already in Allure. Grey boxes are next — they are not in the suite yet.

Test order

  1. Splash (cold launch → first stable UI)
  2. Language selection (English + Get started)
  3. Onboarding slide 1 (Skip / Next)
  4. Onboarding slide 2 (Get started)
  5. Sign up (phone, +91, terms, Get OTP visible)
  6. OTP screen (open only — valid OTP is not submitted in this suite)
  7. Home, then Calendar / Earning / Fleet / Profile & settings — not started
